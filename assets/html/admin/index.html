Architecture

GUI clients poll the face service, which calls smiley (HTTP) and color (gRPC) in parallel to compose the response.

Architecture

The publisher fetches a face from smiley (HTTP) and color (gRPC), writes it to MySQL, and pushes to the queue. The subscriber pops messages and serves them to the GUI clients.
